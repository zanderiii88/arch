# Archipelago 0.48 cumulative update

Install over an existing 0.35 or later installation. Extract the ZIP, copy its contents into the repository root, replace matching files and merge assets. Keep existing files not included. Upload the extracted files, not the ZIP itself.

Check for 0.48.0 after deployment; close and reopen if the offline cache is still updating. Intermediate 0.45–0.47 updates are included.
