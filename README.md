# Archipelago 0.95 - Keeping your belongings safe

Cumulative update over a complete installed 0.83 or later. Replace matching files, merge assets and retain everything else. Not standalone. The source checkpoint's dist contains cumulative changed files, not the full game. Nothing pushed or deployed.

Single-item bin confirmation now rejects closed, replaced, cancelled or stale actions. If the item or stack changes before confirmation, nothing is removed. A compact panel keeps the item, warning and all three choices visible together on short phones, using the existing shared artwork and UI.

Main/Story test saves, inventories, progression, ferry rules and session-only DEV travel remain. Golf is unchanged and deferred until after Stuart. Read RELEASE-NOTES.md for automatic/browser checks and phone-review limits; FUTURE-BUILDS.md for remaining work; ART-STYLE.md for mandatory visual rules.
