# Archipelago 0.47 cumulative update

Install over an existing 0.35 or later installation. Extract the ZIP, copy its contents into the repository root, replace matching files and merge assets. Keep existing files not included. Upload extracted files, not the ZIP itself.

After deployment check for version 0.47.0 on the title screen. Close and reopen the game if the offline cache is still updating.

To test from the start without replacing your main save: Island stories > Story test > New game. Catch two fish, wait for the next morning’s route news, meet Jamie and Ben, and complete their chopping and sawing lessons. Ask about the community project, supply ten boards and the two parts, then finish together.

This package includes 0.45 and 0.46; no separate intermediate upload is needed.
